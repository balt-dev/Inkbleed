# Inkbleed

Reimplements the Misprint Deck, as seen in Cryptid, outside of it!

This reimplementation uses an alternative algorithm leveraging log-normal randomness instead of log-uniform,
which means that multipliers can be theoretically infinite, but get rarer as they get more drastic.

Note that some cards may be a little broken, YMMV.

Supports CardSleeves!

## Usage

You can download a .zip of the mod using the "Download ZIP" button under the "Code" dropdown in GitHub's UI, or by clicking [here](https://github.com/balt-dev/inkbleed/archive/refs/heads/trunk.zip).
